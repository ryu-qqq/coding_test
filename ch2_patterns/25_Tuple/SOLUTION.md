# 튜플 (Programmers 64065) — 해설

> 막히기 전에 골격(`Tuple.java`)부터 직접 채워보고, 그래도 안 풀리면 이 문서를 펼쳐보세요.

## 문제
집합으로 표현된 튜플 문자열에서 원래 튜플 (a1, a2, ..., an) 을 복원한다. 집합들의 나열 순서는 뒤섞일 수 있다.
예: `"{{2},{2,1},{2,1,3},{2,1,3,4}}"` → `[2, 1, 3, 4]`.

## 핵심 직관 (1줄)
원소의 **등장 빈도가 곧 튜플 순서**다. 빈도가 큰 원소일수록 앞.

왜? 튜플 (a1, a2, ..., an) 은 집합 {a1}, {a1,a2}, ..., {a1,...,an} 으로 표현된다. a1 은 n개 집합 **모두**에, a2 는 n-1개에, ... an 은 1개에만 등장한다. 그래서 빈도 내림차순이 원래 순서.

## 자료구조
- `Map<Integer, Integer> freq` : 원소 → 등장 횟수.

## 알고리즘
1. 정규식으로 집합 단위 `{숫자,숫자,...}` 를 모두 찾고, 그 안 숫자들을 `freq` 에 카운트(`merge`).
2. `freq` 를 값(빈도) 내림차순 정렬.
3. key 만 순서대로 뽑아 `int[]` 로 반환.

## 불변식
파싱 종료 시 `freq[x]` = x 가 등장한 집합 개수. 정렬 후 빈도 내림차순 = 튜플 순서(빈도가 모두 distinct 함이 문제로 보장됨).

## 복잡도
- 시간: 파싱 O(L) (L = 문자열 길이) + 정렬 O(M log M) (M = 서로 다른 원소 수, ≤ 500).
- 공간: O(M).

## 함정 ⚠️ (정규식 / 파싱 집중)
- **집합 단위 매칭 정규식**: `\\{(\\d+(?:,\\d+)*)\\}`
  - `\\{`, `\\}` : `{`, `}` 는 정규식 수량자 문법(`{2,}`)에 쓰이는 메타문자라 이스케이프. Java 문자열이므로 `\\{`.
  - `\\d+` : 숫자 1개 이상. `(?:,\\d+)*` : ",숫자" 가 0회 이상 반복(**비캡처 그룹** `(?:...)` — 그룹 번호를 차지하지 않아 `m.group(1)` 이 깔끔히 내부 전체를 가리킴).
  - `( ... )` 바깥 그룹 1 = 중괄호 안 숫자 나열 전체.
- **더 단순한 파싱 대안**: 바깥 `{{`, `}}` 제거 후 `},{` 로 split, 또는 아예 `[{}]` 를 모두 지우고 `,` 로 평탄화해서 카운트해도 같은 결과(빈도만 필요하므로 집합 경계가 사실 불필요).
- **`merge` 카운트**: `freq.merge(num, 1, Integer::sum)` — "없으면 1, 있으면 +1".
- **Stream 정렬 타입 명시**: `Comparator.comparingInt(Map.Entry<Integer,Integer>::getValue).reversed()` 처럼 제네릭을 명시하지 않으면 타입 추론이 막힐 수 있다.

## 대안 / 최적화
- 정규식 없이 `s.replaceAll("[{}]", "")` 후 `,` split 하여 카운트(이 문제는 빈도만 보므로 집합 구분 불필요). 가장 짧다.

## 면접 답변 (한국어 1분)
> "핵심 관찰은 원소의 등장 빈도가 곧 튜플 순서라는 점입니다. 튜플 (a1..an) 은 {a1}, {a1,a2}, ... 로 표현되니 a1 은 모든 집합에, a2 는 하나 적게, an 은 한 집합에만 등장합니다. 그래서 빈도 내림차순이 원래 순서죠. 파싱은 정규식 `\\{(\\d+(?:,\\d+)*)\\}` 로 집합 단위를 잡고 비캡처 그룹으로 내부 숫자만 깔끔히 캡처해서 merge 로 카운트했습니다. 사실 빈도만 필요해서 중괄호를 다 지우고 콤마로 쪼개 세도 됩니다. 마지막에 빈도 내림차순 정렬 후 key 를 뽑으면 정답입니다. 파싱 O(L), 정렬 O(M log M) 입니다."

## Follow-up
- **`(?:...)` 와 `(...)` 차이?** 전자는 비캡처 그룹(그룹 번호 미할당), 후자는 캡처 그룹. 캡처가 필요 없는 반복 묶음엔 비캡처가 효율적이고 그룹 번호가 깔끔.
- **빈도가 같은 원소가 있으면?** 이 문제는 튜플 정의상 빈도가 모두 distinct 라 동점이 없다.
