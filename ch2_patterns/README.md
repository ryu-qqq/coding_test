# Ch2. 대표 알고리즘 유형

## 풀이 순서 추천

1. **해시/투포인터**(01~05)로 워밍업 — 가장 빈출, 손 풀기 좋음.
2. **트리 재귀**(06~11) → **그래프**(12~14): 재귀/BFS 템플릿 체화.
3. **힙**(15~17) → **DP**(19~22): 점화식 세우는 연습.
4. **문자열**(23~29): 자바 String API/정규식 약점 보강. 23(NewId)는 정규식 종합세트.
