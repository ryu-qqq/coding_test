# Same Tree (LC 100) — 해설

> 막히기 전에 골격(`SameTree.java`)부터 직접 채워보고, 그래도 안 풀리면 이 문서를 펼쳐보세요.

## 문제
두 이진 트리가 구조와 값 모두 동일한지 판별한다.

## 핵심 직관 (1줄)
두 트리를 같은 좌표로 동시에 따라가며 비교한다.

## 자료구조
- 재귀.

## 알고리즘
- 둘 다 null → true. 한쪽만 null → false. val 다르면 false. 그 외 좌/우 재귀 (둘 다 true여야 true).

## 불변식
재귀 호출 시점 p, q는 두 트리의 같은 좌표에 위치한다.

## 복잡도
- 시간: O(N)
- 공간: O(H)

## 함정 ⚠️
- null 체크 순서: 둘 다 null 먼저, 그 다음 한쪽 null.
- 구조 비교를 빠뜨리면 안 된다 (한쪽 null 케이스에서 잡힌다).

## 대안 / 최적화
BFS 큐에 `(p, q)` 쌍을 넣고 동시에 순회하는 iterative 방식도 가능하다.

## 면접 답변 (한국어 1분)
> "재귀로 두 트리를 같은 좌표로 동시에 내려가면서 비교합니다. 첫 번째 base case는 둘 다 null이면 true,
> 두 번째는 한쪽만 null이면 false, 세 번째는 값이 다르면 false입니다. 모두 통과하면 좌우 서브트리에
> 대해 재귀 호출하고 둘 다 true여야 true입니다. 순서를 둘 다 null → 한쪽 null 순으로 두는 게 NPE
> 방지에 중요합니다. 시간 O(N), 공간 O(H)입니다."

## Follow-up
- **이터레이티브로 풀려면?** 큐에 `(p, q)` 쌍을 넣고 BFS로 동시에 순회하며 매 쌍에서 같은 비교를 한다.
