# Maximum Depth of Binary Tree (LC 104) — 해설

> 막히기 전에 골격(`MaxDepth.java`)부터 직접 채워보고, 그래도 안 풀리면 이 문서를 펼쳐보세요.

## 문제
이진 트리의 최대 깊이(루트 → 가장 먼 leaf 까지의 노드 수)를 구한다.

## 핵심 직관 (1줄)
깊이 = `1 + max(좌 깊이, 우 깊이)`. null이면 0.

## 자료구조
- 재귀 (호출 스택 사용).

## 알고리즘
- `maxDepth(node) = node == null ? 0 : 1 + max(maxDepth(node.left), maxDepth(node.right))`.

## 불변식
재귀 반환값은 그 서브트리의 최대 깊이다.

## 복잡도
- 시간: O(N)
- 공간: O(H) (재귀 스택, 균형이면 log N, 치우치면 N)

## 함정 ⚠️
- `null → 0` base case를 빠뜨리면 NPE.
- 한쪽만 자식이 있어도 양쪽 max 비교가 필요하다.

## 대안 / 최적화
BFS 큐로 레벨을 카운트할 수도 있다 (공간 O(W), W = 최대 너비).

## 면접 답변 (한국어 1분)
> "전형적인 재귀 풀이입니다. 빈 노드는 깊이 0이고, 그렇지 않으면 좌우 서브트리 깊이의 max에 1을
> 더하면 됩니다. 한 줄로 깔끔하게 표현됩니다. 시간은 모든 노드를 한 번 방문하니 O(N), 공간은 재귀
> 스택 깊이 O(H)입니다. 균형 트리면 H가 log N이지만 한쪽으로 치우치면 H가 N이 됩니다."

## Follow-up
- **재귀 스택 오버플로우를 피하려면?** BFS 큐로 풀거나 명시적 스택을 쓴 iterative DFS를 사용한다.
  트리가 매우 한쪽으로 치우친 경우 안전하다.
