# 신규 아이디 추천 (Programmers 72410) — 해설

> 막히기 전에 골격(`NewIdRecommendation.java`)부터 직접 채워보고, 그래도 안 풀리면 이 문서를 펼쳐보세요.

## 문제
입력 `new_id` 를 7단계 규칙대로 순서대로 변환한 결과를 반환한다.
1) 대문자→소문자 2) 허용 문자(소문자/숫자/`-`/`_`/`.`) 외 제거 3) 연속된 `.` 하나로 4) 양끝 `.` 제거
5) 빈 문자열이면 `"a"` 6) 길이 16 이상이면 15자로 자르고 끝 `.` 제거 7) 길이 2 이하이면 마지막 문자를 채워 3자로.

## 핵심 직관 (1줄)
규칙을 "순서 그대로" 절차적으로 옮긴다. 한 단계 = 한 줄(정규식) 또는 작은 if 하나.

## 자료구조
- 별도 자료구조 없음. `String` 하나를 단계마다 갱신.

## 알고리즘
1~4단계는 정규식 `replaceAll`, 5~7단계는 `length()` 체크 + if. 순서를 절대 바꾸면 안 된다(6단계 자르기 후 다시 끝 `.` 제거가 필요한 이유).

## 불변식
각 단계 종료 시점에서 `word` 는 "그 단계까지의 규칙이 모두 적용된 문자열". 다음 단계는 이전 단계 결과만 본다.

## 복잡도
- 시간: O(N) (N = `new_id` 길이, 정규식 스캔 상수 횟수)
- 공간: O(N)

## 함정 ⚠️ (정규식 / String API 집중)
- **2단계 부정 character class**: `replaceAll("[^a-z0-9_.-]", "")`.
  - `[...]` 안의 글자는 "한 글자 후보 집합". `replaceAll` 은 **잡은 글자를 치환**하는 모델이라, 허용 글자를 그대로 두려면 **잡는 대상을 뒤집어야** 한다.
  - `[ ]` **맨 앞** `^` 가 부정(negation, 여집합). `[^a-z0-9_.-]` = "허용 글자가 **아닌** 한 글자" → 그걸 `""` 로 제거.
  - ⚠️ `^` 가 `[ ]` **밖**에 오면 "문자열 시작"이라는 전혀 다른 의미(4단계에서 쓰는 `^\\.`).
  - ⚠️ class 안에서 `-` 는 보통 범위 기호지만 **맨 끝**(`...-]`)에 두면 리터럴 하이픈으로 안전. `.` 도 class 안에서는 그냥 점(이스케이프 불필요).
- **3단계 메타문자 점 + 수량자**: `replaceAll("\\.{2,}", ".")`.
  - 정규식에서 `.` 은 "아무 한 글자"(메타문자). 진짜 점을 매치하려면 `\.` 로 이스케이프. Java 문자열에서는 `\` 를 또 이스케이프해야 하므로 `"\\."` 로 적는다(Java `\\` → 정규식 `\`).
  - `{2,}` = "2번 이상". `..` 라고 쓰면 "아무 글자 2개"라 비-점 글자까지 잡혀 망한다.
- **substring 양끝 제거**: 끝 점 제거는 `substring(0, length()-1)`. `substring(0, length())` 는 "처음부터 끝까지"라 아무것도 안 잘린다.
- **7단계 무한루프**: `while(len < 3)` 안에서 `len` 을 갱신하지 않으면 영원히 돈다. `word += ...` 와 함께 `len++` 동기화 필수.

## 대안 / 최적화
- 4단계도 정규식 한 줄로: `word = word.replaceAll("^\\.|\\.$", "")` (`^\\.`=시작 점, `\\.$`=끝 점, `|`=OR).
- 7단계를 `StringBuilder` 로 채워도 되지만 길이가 최대 3이라 차이 미미.

## 면접 답변 (한국어 1분)
> "문제의 7단계 규칙을 순서 그대로 절차적으로 옮겼습니다. 1~4단계는 정규식 replaceAll 한 줄씩으로 처리했는데, 2단계가 핵심입니다. replaceAll 은 '잡은 글자를 치환'하는 모델이라 허용 글자만 남기려면 잡는 대상을 뒤집어야 합니다. 그래서 character class 맨 앞에 부정 기호 ^ 를 붙여 `[^a-z0-9_.-]`, 즉 허용 글자가 아닌 것을 잡아 빈 문자열로 제거했습니다. 3단계는 점이 정규식 메타문자라 `\\.` 로 이스케이프하고 `{2,}` 수량자로 2회 이상 연속을 하나로 줄였습니다. 5~7단계는 길이 체크와 if 로 처리했고, 7단계 while 에서 길이 변수를 같이 갱신해 무한루프를 피했습니다. 전체 O(N) 입니다."

## Follow-up
- **`[^...]` 의 `^` 와 `^\\.` 의 `^` 차이?** 전자는 class 안 맨 앞이라 부정(여집합), 후자는 class 밖이라 "문자열 시작". 위치로 의미가 갈린다.
- **왜 `"\\."` 인가?** Java 문자열 리터럴에서 `\` 가 이스케이프 문자라, 정규식 엔진에 `\.` 한 개를 보내려면 소스에 `\\.` 두 개를 적어야 한다.
- **`replace` 와 `replaceAll` 차이?** `replace` 는 리터럴 치환(정규식 X), `replaceAll` 은 첫 인자가 정규식. 이 문제는 정규식이 필요하므로 `replaceAll`.
