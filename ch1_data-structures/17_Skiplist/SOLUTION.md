# Skiplist (LC 1206) — 해설

> 막히기 전에 골격(`Skiplist.java`)부터 직접 채워보고, 그래도 안 풀리면 이 문서를 펼쳐보세요.

## 문제
정렬된 자료구조에서 평균 O(log n)으로 `search(target)`, `add(num)`, `erase(num)`(없으면 false)을 지원한다. 중복 값을 허용하고, `erase`는 한 개만 제거한다. 균형 트리(AVL/Red-Black)의 확률적 대안(Redis sorted set의 기반).

## 핵심 직관 (1줄)
여러 레벨의 정렬 연결 리스트를 겹쳐 둔다. 상위 레벨일수록 노드가 듬성듬성해 "건너뛰기"가 커지고, 위에서 아래로 내려오며 탐색하면 이진 탐색처럼 평균 O(log n)에 위치를 좁힌다.

## 자료구조
- `Node` : `int val` + `Node[] forward` (forward[i] = 레벨 i에서의 다음 노드).
- `head` : sentinel 노드(항상 MAX_LEVEL 높이, 값은 의미 없음).
- `level` : 현재 사용 중인 최고 레벨.
- `MAX_LEVEL`(=16), `P`(=0.5) : 레벨 상한과 동전 확률.

## 알고리즘
1. `randomLevel()` : `rng < 0.5`인 동안 레벨을 +1(기하분포). 평균적으로 노드의 절반은 레벨 0, 1/4은 레벨 1 ... 식으로 분포.
2. `search(target)` : `head`에서 시작해 `level`부터 0까지, 각 레벨에서 `forward[i].val < target`인 동안 전진하다 다음 레벨로 내려간다. 레벨 0에서 다음 노드가 target이면 존재.
3. `add(num)` : search와 같은 하강을 하되, 각 레벨에서 멈춘 직전 노드를 `update[i]`에 기록. `randomLevel()`로 새 노드 높이를 정하고, 0..newLevel 각 레벨에서 `update[i]` 뒤에 끼워 넣는다(연결 리스트 삽입).
4. `erase(num)` : 동일하게 `update[]`를 구하고, 레벨 0의 다음 노드가 num이면 그 노드가 존재하는 모든 레벨에서 링크를 우회해 **한 개만** 제거. 최상위 레벨이 비면 `level`을 낮춘다.

## 불변식
- 각 레벨의 리스트는 항상 정렬 상태.
- 레벨 k에 존재하는 노드는 레벨 0..k 모두에 존재한다(forward 배열 크기가 level+1).

## 복잡도
- search/add/erase 모두 **평균** O(log n). 최악은 O(n)이지만 확률적으로 극히 드물다.
- 공간: 기대값 O(n)(노드당 평균 forward 길이가 상수, `1/(1-P)=2`).

## 함정 ⚠️
- **`< target` (strict) 으로 전진**해야 한다. `<=`로 하면 target 노드 자체를 지나쳐 search/erase가 깨진다.
- erase는 target이 존재하는 레벨에서만 우회해야 한다. `update[i].forward[i] != target`이면 그 위 레벨엔 없으므로 멈춘다.
- 중복 허용: 같은 값을 여러 번 add하면 별도 노드가 여러 개 생기고, erase는 레벨 0 기준 가장 앞 한 개만 지운다.
- `add`에서 새 레벨이 기존 `level`보다 크면 그 사이 레벨들의 `update[i]`를 `head`로 채워야 한다.

## 대안 / 최적화
- 균형 트리(AVL/Red-Black)는 최악도 O(log n)을 보장하지만 회전 로직이 복잡하다. skiplist는 구현이 단순하고 동시성 친화적이라 Redis 등에서 선호.
- 카운트를 노드에 저장하면 중복 erase를 O(1) 카운트 감소로 처리할 수도 있다(여기선 노드 분리 방식).

## Follow-up
- **왜 동전 던지기로 레벨을?** 노드 높이를 기하분포로 분산시켜 평균적으로 균형 잡힌 다단 인덱스를 만든다. 결정적 균형(트리 회전) 없이 확률적으로 O(log n)을 얻는다.
- **최악 O(n)인데 괜찮나?** 모든 노드가 같은 레벨이 될 확률이 지수적으로 작아 실무에선 사실상 O(log n).
- **균형 트리 대비 장점?** 구현이 단순하고 lock-free/동시성 구현이 쉬워 분산/인메모리 시스템에서 선호.
